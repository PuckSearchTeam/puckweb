Puck: a coupling-constraint checker for IntelliJ

Welcome to the Puck plugin page! Here you can find the latest downloads, updates, and instructions for using the Puck plugin with IntelliJ.

Puck is an IntelliJ plugin that checks coupling constraints on Java code. It builds the dependency graph of a project, reads the constraints from a decouple.wld file at the project root, and reports every violation in the program text, where the IDE reports errors, and in a log. Puck identifies the dependencies to remove; it does not perform the refactorings that remove them.

Weland is the language of that file. Its core predicate is hide X from Y;, where X and Y are sets of named Java elements (packages, classes, fields, methods, constructors): no element of the transitive closure of X may appear in the scope of any element of the transitive closure of Y. Rather than writing such clauses one by one, a file declares the project's axes of change (axis rules = [org.example.domain]), the order in which they change (speed rules < policy < adapters;, the slowest first), which entities are harder to change than others (difficulty), and which unordered axes must stay apart (apart). The hide clauses follow: each axis is hidden from the axes that change less often, the easier from the harder, and the axes kept apart from one another. Decisions of the architect complete the file: friend F of X; exempts a privileged client such as the composition root, separate X; keeps the members of a set apart, and the predefined set tests leaves the tests out of the rules. Hand-written clauses remain available.

Puck runs from the Tools menu or headlessly from the command line, and reports the violations of each clause, the axis mismatches (an entity tagged with an axis other than its container's), and the totals, with or without the optional decisions of the file.
