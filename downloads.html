Download the latest version of the Puck IntelliJ plugin here (version 1.0-SNAPSHOT, built on 16 October 2026 from the current sources; requires IntelliJ IDEA 2024.3 or later with the Java plugin).

You can then install the plugin as follows:

  • Open IntelliJ
  • Select "Plugins"
  • Click on the toothed wheel
  • Select "Install Plugin from Disk..."

Then open a Java project that has a decouple.wld file at its root and run Tools → Puck. The violations appear in the editor and in puck.log next to the file.
